## Direction (options for the maintainer, not ranked against the bugs)

- **A checked-in shader sweep.** The commit message of `cf66896a57` reports a check against
  3,576 local shader dumps, done with a tool written for that one change, and
  `tools/shader-sweep/fixtures/` holds a single fixture that nothing reads. A small harness that
  runs `LowerToMaxwell` over a local dump folder and prints which programs changed between two
  builds (accepted, refused, different output) would make that check repeatable for every
  lowering change. Trade-off: game shader dumps cannot be committed, so the corpus stays local
  and only the tool and a few hand-made fixtures go into the repository. Effort: M (coarse).
- **Compatibility table from measured data.** `README.md:92-116` is written by hand, while
  `docs/performance/*.json` holds 14 dated run records with title, scene and fps. The two already
  disagree (Orbitals). A script that rebuilds the table from the records, with a hand-written
  notes column, keeps the public statement tied to evidence. Trade-off: the records do not share
  one schema yet, so a minimal common record has to be agreed first. Effort: M (coarse).
- **Generated list of environment switches.** Finding 20 as a feature: a script that greps the
  switch names and fails when `docs/EnvSwitches.md` lacks one. Cheap, and it turns a stale name
  into a visible diff. Trade-off: someone has to write one line per existing switch once.
  Effort: M (coarse).
- **Fork-scan pre-filter.** `docs/IssueFixStatus.md` counts 1,749 commit references in nine open
  scans, triaged by hand. `tools/fork-scan.sh` could drop commits that only touch paths Orchid
  does not ship (Android, translations, other projects' CI) and record them in
  `.github/fork-scan-skip` with a generic reason. Trade-off: a path filter can hide the rare
  relevant commit that also touches such a path. Effort: S-M (coarse).

## Findings considered and rejected

- `ReinterpretImage` scales the copy width by `bpp_out / bpp_in` for D32S8 sources
  (`vk_texture_cache.cpp:1448-1462`): not a bug. The copy reinterprets bytes, and the depth plane
  really is 4 bytes per texel, as the comment there says.
- Unit tests run only on manual dispatch (`tests.yml`): documented decision in the workflow file.
- `getenv` on hot paths: the sites that were opened cache the value in a `static`.
- `src/tests/common/host_memory_commit.cpp` not in the test list: it is, under `if (WIN32)`.
- No tests for the update checker, the loose-directory loader or `video_core/nx2.h`: they have
  tests (`static_assert`s in `update_checker.cpp`, `loose_directory.cpp`, five `nx2_*` tests).
- Compile-time cost of `nx2_gsv.h`: only one `.cpp` includes it.
- "Title IDs are defined in many places": only one ID is defined twice (Xenoblade 2, in
  `game_presets.h:147` and `vk_rasterizer.h:162`). Not worth a shared header yet.
- Splitting the 3,900-line `LowerToMaxwell` function out of its header: not now. The file had 168
  commits in 30 days; a mechanical split would collide with all work in progress. Revisit when
  the lowering work slows down.
- Texture destination spans crossing the uniform register mirror in three TLD/TEX lowerings:
  real encodings use an aligned explicit second destination; no practical impact found.
- Dependency versions past their support window (Qt 6.8.3, OpenSSL 3.6 source fallback):
  unconfirmed without network access; not reported as findings.
- HLE stubs that report success, per-title patches and defaults, `EDEN_*` switches as a
  mechanism, old names in identifiers: settled decisions of this project.
